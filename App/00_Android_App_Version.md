# Tanu Classes जैसी Android Education App का V1 → V2 → V3 Roadmap

हम आपकी MERN Stack Education Platform के लिए एक अलग Android App विकसित करेंगे, जो वेबसाइट के उसी Backend, MongoDB Database, student accounts, courses और enrollments का उपयोग करेगी।

हमारा लक्ष्य होगा कि V1 में विद्यार्थी ऐप से लॉगिन करके खरीदे हुए कोर्स पढ़ सकें, V2 में Advanced LMS features मिलें और V3 में ऐप एक Professional Education Platform बन जाए।

### V1 का Acceptance Criteria

V1 को तब पूरा मानेंगे जब ये सभी flows सही तरीके से काम करें:

- विद्यार्थी Android App install करके login कर सके।
- वेबसाइट पर खरीदे हुए कोर्स उसी account में दिखाई दें।
- App में course, sections और lessons खुलें।
- केवल enrolled विद्यार्थी paid lessons देख सके।
- Lesson progress सुरक्षित रूप से Backend पर save हो।
- Logout के बाद protected content बिना authentication के न खुले।
- App के बंद होने या दोबारा खुलने पर विद्यार्थी अपनी learning जारी रख सके।

## Website और Android App का Architecture

Website

React + Vite

Android App

React Native + Expo

Shared Backend API

Node.js + Express + TypeScript

Authentication · Courses · Enrollments · Payments · Progress

MongoDB Atlas

Shared users, courses, orders और learning data

इस architecture में Android App का frontend अलग लिखा जाएगा, लेकिन Backend और database को दोबारा बनाने की जरूरत नहीं होगी।

## Development का सही क्रम

### V1 Implementation Sequence

1. Foundation: React Native + Expo + TypeScript project setup
2. Design system: Colors, typography, reusable components और navigation
3. Authentication: Login, registration, secure token/session handling
4. Course catalog: Home, search, course details और pricing
5. Student LMS: My Courses, sections, lessons और PDFs
6. Video integration: Playback, access authorization और error handling
7. Progress: Lesson completion और Backend synchronization
8. Testing: Android devices, network errors, permissions और security
9. Release: App icon, splash screen, signed build, testing track और Play Store submission

## Recommended Android Technology Stack

| Layer                | Technology                                                  |
| -------------------- | ----------------------------------------------------------- |
| Mobile framework     | React Native + Expo                                         |
| Language             | TypeScript                                                  |
| Navigation           | Expo Router                                                 |
| API integration      | Fetch या Axios + TanStack Query                             |
| Forms                | React Hook Form + Zod                                       |
| Secure local storage | Expo SecureStore, उपयुक्त token/session design के साथ       |
| Local preferences    | AsyncStorage, केवल non-sensitive data के लिए                |
| Backend              | मौजूदा Node.js + Express API                                |
| Database             | मौजूदा MongoDB Atlas                                        |
| Testing              | Jest/React Native Testing Library और Android device testing |
| Build और release     | EAS Build या Android native build workflow                  |

## V1, V2 और V3 के लिए एक महत्वपूर्ण निर्णय

हम Android App को शुरू से ही वेबसाइट के Backend के साथ compatible बनाएँगे। इससे वेबसाइट पर course खरीदने वाला विद्यार्थी उसी account से App में login करके सीख सकेगा, और V2/V3 के features बाद में क्रमशः जुड़ेंगे।

अभी पहला लक्ष्य: V1 का एक working Android MVP बनाना है, जिसमें Login → My Courses → Course Lessons → Video Playback → Progress Tracking का पूरा flow सफल हो। इसके बाद assessments, notifications, live classes और offline learning जोड़ेंगे।
